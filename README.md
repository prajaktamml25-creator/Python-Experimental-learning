# Library Management System

## Problem Statement

Develop a Python-based system to manage books, members, and library transactions efficiently.

## Objectives

* Add, search, update, and delete books.
* Register and manage library members.
* Issue and return books.
* Calculate overdue fines.
* Store records permanently using file handling.

## Algorithm

1. Start the program.
2. Load stored records.
3. Display the menu.
4. Perform the selected operation.
5. Update and save records.
6. Repeat until Exit is selected.
7. End the program.

## Python Concepts Used

* Variables and Data Types
* Lists and Dictionaries

* If-Else Statements
* File Handling
* Exception Handling
